# 基础数据库初始化

`order_base_20260803.sql` 从当前开发库的最新结构生成，目标数据库名为
`order`，与后端默认 JDBC 数据库名一致，适用于 MySQL 8.x。

文件完整性校验值见 `SHA256SUMS.txt`。

## 保留的数据

- 后台管理员、部门、角色、菜单、权限关联
- 系统参数、字典、定时任务配置、时区
- 网站、交易等 `order_config` 配置
- 商品目录、商品分类、Banner、客服、会员等级、提现类型
- 公告、翻译、活动定义、奖品定义、积分礼品等基础配置
- 代码生成器元数据

## 不包含的数据

- H5 会员与会员登录记录
- 订单、订单请求幂等记录、连单、彩金、序列进度
- 充值、提现、提现账户、资金流水、每日提现额度
- 站内信、网站客户
- 操作日志、登录日志、任务执行日志
- 上传文件及文件引用记录
- 旧系统兼容业务记录、积分账户及积分流水

所有表结构均会保留，上述业务表初始化后为 0 行。

## 恢复

请只在全新部署或允许重建 `order` 数据库全部表的环境中执行：

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p < order_base_20260803.sql
```

脚本会创建并使用 `order` 数据库。若该库已存在，脚本中的表级
`DROP TABLE IF EXISTS` 会重建全部表结构，因此不要对包含需保留业务数据的
`order` 库执行。导入后后端默认 JDBC 配置无需修改数据库名。
